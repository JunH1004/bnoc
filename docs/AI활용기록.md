- AI 사용: `spec_mapper`가 현재 계약과 이전 업무 해석 실패를 읽기 전용으로 분석. 메인은 OpenAI·Anthropic 공식 자료, GitHub Spec Kit·Superpowers 저장소, METR 연구 설명을 조사하고 [비교·도입안](AI개발방식_비교와도입안.md)과 `experiments/ai-workflow/`를 작성했다. 구현 명세·제품 코드·의존성은 변경하지 않았다.
- 채택 산출물: 일정 주체·미정 허용 검사 3개와 원본/오류 복사본 비교 실행기. 새 AI 기능을 제품에 탑재한 작업이 아니다. 실제 사용자 지시·생성 파일·시험 증거를 이 작업 커밋으로 연결한다.
- 실행: 원본은 기존 단위 27/27·추가 검사 3/3 통과. BNOC 배정 시 일정을 자동 입력하도록 수정한 임시 복사본은 기존 27/27 통과·추가 검사 2통과/1실패. 의도한 일정 금지 assertion의 실패와 제품 소스 해시 불변을 확인했다. 결과는 `runtime/evidence/ai-workflow-20261013/`에 보존.
- 독립 역할: `reviewer`가 업무 근거·공식 출처 주장·실험 증거를 대조해 수정 지적 없음. `verifier`가 새 폴더에서 재실행해 같은 결과와 소스 41개 불변을 확인. 지적한 문서의 잘못된 절 번호는 정정했다. 이들은 제품·실험 소스를 수정하지 않았다.
- 한계: 오류 하나를 의도적으로 선정한 탐색적 시험. 검사 능력 점검이지 AI 방식 간 비교나 생산성·예방률 증거가 아니다. 후속 6회 비교는 계획이며 미실행. 현업 검수·새 화면·공개 배포·실제 SSO도 이번에 수행하지 않았다.

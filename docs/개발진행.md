## 2026-10-14 · 완성도 고도화 중간 목표·제안

사용자가 기본 구현·안정화와 설문/실무 의견 기반 추가 기능 사이에 완성도 고도화를 추가했다. 현재는 [분석·개선안·개선 결과 기준](작업기록.md#quality-improvement-20261014)의 제안 단계다. 기능·저장 안전성에는 기존 증거가 있지만 화면의 의미·정보 우선순위·오류/저장/조회 안내·현업 사용성은 별도 확인이 필요하다.

기존 소스 대조에서 유형 그룹 오류와 화면 선택칸 안내의 연결 빈틈을 찾았으며 실제 화면 재현은 미실행이다. 기존 PNG에서는 모바일 활성 메뉴 숨김과 필터·부서 카드 뒤로 밀리는 목록을 확인했다. 우선순위는 입력 오류 안내, 저장/조회 결과 구분, 용어·탐색, 목록/선택 입력 배치, 표현/부서·날짜 피드백, 실사용·시연 측정이다. 개별 개선안·종료 기준은 AI 제안이며 새 업무·UI 개편 승인으로 취급하지 않는다. 현재 제품·기능 명세·아키텍처 웹은 변경하지 않았다. 이번 새 제품 검사·사용 시간 측정은 없으며, 아래 통과 결과는 이전 수행판 기록이다.

## 2026-10-14 · 화면 문구 정정·공개 반영

로그인·상단·인증 창·GPS/CPCON 화면에서 모의/대회용 문구와 실제 연동 여부 설명을 제거했다. 정보원 이름·단계·시각·수집 상태는 유지했다. 업무·인증·권한·저장 동작과 내부 sourceMode는 그대로다. 핵심 명세·설계 웹·AGENTS에도 같은 표시 기준을 반영했다. [현재 공개 사이트](https://vessel-cups-electric-spa.trycloudflare.com)에 새 패키지를 반영했다.

화면 단위 48/48·제공자 3/3·서버 35/35·빌드, 설계 정적/6조합과 기존 로그인·상황 UI 12/12를 통과했다. 독립 공개 검사 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/ui-text-20261014/independent-public-057cc4ad/results.json`)는 8/8: Chrome/Firefox와 390/1280/1440에서 실제 팝업·로그인·역할 전환·상단·상황·직접 경로/새로고침·키보드·가로 넘침, 배포 자산 해시를 확인했다. 공개 업무 자료를 쓰지 않았다. 상황의 오류 표시는 브라우저 응답 복사로만 관찰했다. 검토 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/ui-text-20261014/reviewer.json`)·실행 요약 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/ui-text-20261014/verification.json`). 이번 문구 변경에서 전체 업무/저장/감도 검사나 실제 공군 연결을 새로 검증한 것은 아니다. 공개 주소의 컴퓨터·서버·터널 실행 의존은 유지된다.

## 2026-10-14 · 새 백엔드의 공개 HTTPS 시연

현재 이용 주소: **[BNOC 업무·부대 운영](https://vessel-cups-electric-spa.trycloudflare.com)**. 앞서 로컬 주소만 전달한 오류를 정정했다. 새 Spring JAR·MySQL·비공개 첨부·모의 인증/GPS/CPCON 서버를 사용하는 공개 시연이다. 예전 Sites 정적 데모와 다르다. 컴퓨터·MySQL·서버·터널이 실행 중이어야 하며 터널을 새로 시작하면 주소가 바뀐다. 상시 호스팅 계정 연결은 미완료다.

전용 8085/8086·별도 DB/첨부/비밀을 사용하고 기존 8081/8083 자료를 복제하지 않는다. 브라우저 로그인은 공개 Origin의 정확한 `/identity`, 서버의 검증·상황 수집은 loopback이다. 내부 발급/검증·제어·원시 feed는 공개하지 않는다. 업무 주체·분류·일정·상태·권한은 설계 0.7 그대로다.

검증: 최종 JAR (비공개 출처: `../runtime/evidence/backend-implementation-20261013/public-access-20261014/package.json`) 서버 35/35·화면 단위 48/48·모의 제공자 3/3, 별도 8083 HTTP 26/26·기존 UI 54/54. 독립 공개 결과 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/public-access-20261014/probe-d03422ca/public-access-results.json`) 10/10, Chromium·Firefox의 390/1280/1440·실제 팝업·등록/분류배정/완료·공유/첨부 권한·직접 경로·새로고침·다운로드 bytes·가로 넘침을 확인했다. HTTPS 쿠키 Secure/HttpOnly/Lax·Origin/CSRF와 금지 경로/메서드 95조합도 통과했다. 공개 서버 재시작 후 요청·작업·이력·첨부 hash가 같았고 자기 시험 자료만 정리해 최종 업무 요청·첨부·파일 0을 확인했다. 번호와 세션은 임의로 되돌리지 않았다.

독립 검토 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/public-access-20261014/reviewer.json`) 미해결 finding 0. 여섯 격리 오류 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/public-access-20261014/server-sensitivity-EVhy9J/summary.json`)는 모두 지정 assertion 실패를 확인했다. 설계 정적·6브라우저 조합·기존 9오류 검사도 통과했다. 공개 프로브 두 차례의 파싱/선택자·첨부 예상값 오독은 제품 결함과 구별하고 원코드·실패·정정 근거를 보존했다.

실제 다른 물리 PC·공군 실연동·상시 호스팅·전체 접근성 감사는 미실행이다. 웹 읽기 도구는 해당 주소를 열지 못했으며 성공 증거로 사용하지 않는다. 공개 HTTPS는 실제 Chromium/Firefox와 독립 HTTP 검사로 확인했다. 실행/증거 연결은 검증 요약 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/public-access-20261014/verification.json`)·[업무 검증](업무검증기록.md)에 남겼다.

제품 소스·업무 계약 변경 없이 현업·기술·AI 관점의 독립 모의 심사를 수행했다. 가상 경쟁팀 5팀과 비교한 BNOC 평균은 80.3점·3위이며 실제 대회 순위나 수상 예측이 아니다. [심사 기준·점수·피드백](작업기록.md).

## 2026-10-13 · 설계 0.7 구현·실행 검증 완료

사용자가 승인한 설계대로 단일 Spring 서버·MySQL·비공개 첨부 저장과 실제 API 화면을 구현했다. 자체 회원가입은 없다. 로그인 화면은 역할명만 사용하고 부서 명부 초기값은 비워 둔다. 실제 공군 SSO·GPS·CPCON은 연결하지 않았으며 별도 모의 제공자의 출처를 표시한다.

- 정비: 직접/대리 신청·문서 대기·일반/긴급 배정과 사후 정정·작업반 상태/일정/담당 인원·반환 재배정·미분류 완료 후보고·검색·일/주/월 일정·이력·알림.
- 부대 운영: 전체 작업의 할당/완료/남은 건수와 공유 목록, 각 부서의 명부·휴가/출장/가용·야간 근무, 부서 상호 조회, BNOC 공지와 실제 문서 첨부. 일반 요청자의 공유 조회가 상세정보 권한을 넓히지 않는다.
- 실제 저장: 요청/작업/이력/알림/명부/공지와 파일 내용 보관, 같은 제출 중복 방지·오래된 변경 거절·현재 권한 검사. 최초 배정에 작업 일정을 넣거나 반장을 지정하지 않는다.

현재 서버 27/27·화면 단위 48/48·모의 제공자 3/3·최종 HTTP 26/26 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/runtime-verifier-api-3/api-results.json`) 통과. 실제 MySQL 동시 저장 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/concurrency-final-1791889286897.json`), 알림 저장 실패의 전체 롤백 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/rollback-final-1791889438333.json`), 서버 재시작과 첨부 내용 보존 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/persistence-final-1791889452888.json`)을 확인했다.

화면 검사는 실제 요청·권한·입력·첨부·충돌·키보드·좁은 화면을 두 브라우저와 390/1280/1440 너비에서 확인한다. 첫 실패는 검사 선택자와 준비 시점의 가정 오류였다. 응답 유실 안내 결함의 수정 전 전체 실행은 48/54, 수정 뒤는 52/54였다. 중복 표시명의 인원을 공개 참조로 구분하고 날짜·명부 조회 준비를 확인한 뒤 집중 6/6·전체 UI5 54/54 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/runtime-verifier-ui-5-status.json`)를 통과했다. 두 검사 요소 중 개별 원인까지 확정한 것은 아니다. UI5 육안 확인에서 이력의 분류·시각 코드 노출을 추가로 찾았다. 서버 표시 검사 2건 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/backend-history-display.json`)을 추가하고 원문·권한은 유지했으며 수정 전 실제 여섯 화면 모두 지정 분류 assertion으로 실패했고, 최종판의 배정·재인증/충돌 12개 조합 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/runtime-verifier-ui-7-green-status.json`)은 같은 검사로 통과했다. 분류·한국 시각·원시 field/at·기존 409 조건을 확인했다. 수정 전 화면은 첫 분류 assertion에서 멈췄으므로 시각 오류도 화면 검사가 따로 잡았다고 주장하지 않는다.

최종 패키지 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/package-final-history.json`)는 화면을 JAR에 포함하며 내장 파일과 실제 빌드의 해시를 대조했다. 업무 규칙 격리 오류 검사 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/server-sensitivity-RolEQw/summary.json`)는 정상 코드 통과 후 일정 자동 입력·미분류 배정·다른 로그인 출처·완료 확인 누락 네 오류를 각각 지정 assertion으로 잡았다. 이력 표기 정정 전 실행판이며 선택된 업무 규칙·검사는 최종판과 같다. 표시 정정에는 별도 단위·실제 화면 검사를 적용했다. 실제 실행 결과와 독립 검토·미실행을 구별한다. 실제 공군 연동·인터넷 공개 배포·유예된 이식 고도화는 이번 완료 범위에 포함하지 않는다.

이용 주소: **[http://127.0.0.1:8081](http://127.0.0.1:8081)**. 이 컴퓨터의 실행 중인 제품이다. 독립 접속 확인 (비공개 출처: `../runtime/evidence/backend-implementation-20261013/product-final/independent-verification.json`)은 실제 SSO 팝업·역할 인증·직접 경로·새로고침·390/1440 화면·정적 자산 일치를 확인했다. 요청·공유 작업·명부·조회한 날짜 현황은 비어 있으며 업무 입력·가짜 이름/계급·검증 DB 복사는 하지 않았다. GPS/CPCON 자동 모의 스냅샷과 인증 세션은 정상 생성된다. 최초 접속 하네스의 메뉴/제목 가정 오류는 제품 결함과 구별해 실패 기록도 보존했다.
